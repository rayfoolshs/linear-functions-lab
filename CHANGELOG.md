# Changelog

All notable changes to Linear Functions Lab are recorded here.

## [1.0.0] — 2026-10-28

### Added

- Complete Year 8 learner site with ten guided lessons.
- Interactive algebra tiles, growing tile pattern, function machine, table-to-rule checker, story-to-rule bar model, substitution flow, guided equation solver, balance scale, graph explorer, click-to-plot grid and real-life cost graph.
- Lesson quizzes with hints, explanations and instant feedback.
- Randomised ten-question practice challenge with a final score.
- Saved lesson progress, completion tracking and reset control.
- Mobile navigation, responsive layouts and accessible feedback.
- Version badge in the site footer and sidebar.
- `version.json` release metadata.
- GitHub Pages deployment and GitHub release backup.

### Changed

- Updated the build plan with the student-facing prompts for every visual interactive.
- Updated the todo list with completed build, publication and acceptance checks.
- Improved table-to-graph axis spacing so tick labels are evenly spaced.

### Deployment

- Live site: https://rayfoolshs.github.io/linear-functions-lab/
- Repository: https://github.com/rayfoolshs/linear-functions-lab
- Release tag: `v1.0.0`
