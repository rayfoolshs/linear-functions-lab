Lesson 1

Letters are numbers in disguise

In algebra, a letter stands for a number. It is called a variable because its value can change.

Your goal: explain what 3n means and identify the coefficient and constant in an expression.

1 See it

What does 3n mean?

3n means 3 × n. It does not mean 3 + n.

Example

If n = 4, then:

3n = 3 × 4 = 12

If n = 10, then:

3n = 3 × 10 = 30

In 3n + 5:

3coefficientthe number multiplying n
nvariablethe number that can change
5constantthe number that stays the same
Rule: y = 3n + 5
n01234
y58111417

Notice: every time n goes up by 1, y goes up by 3. That is the coefficient at work.

Lesson 2

Spot the pattern, then write the rule

A linear pattern changes by the same amount each time. Find the step, then use it to predict.

Your goal: find the constant step in a pattern and write a rule for the nth term.

1 See it

A growing tile pattern

Shape number and number of tiles
Shape number, n1234
Number of tiles, t471013

Think it through

  1. The tiles go up by 3 each time. So the multiplier is 3.
  2. Work backwards to Shape 0: 4 − 3 = 1. So the constant is 1.
  3. The rule is t = 3n + 1.
  4. Check Shape 5: 3 × 5 + 1 = 16 tiles.
The easy method: multiplier = how much it goes up each time. Constant = what Shape 0 would be.

What if the pattern goes down?

For 20, 18, 16, the step is −2. Work backwards: 20 + 2 = 22. The rule is y = −2n + 22.

Function machines

Input, rule, output

Input and output values

Working backwards

If the output is 15, what was the input?

Undo the machine in reverse order: 15 − 3 = 12, then 12 ÷ 2 = 6.

Lesson 4

From a table to a rule

A table shows pairs of input and output values. You can use the pattern to write the rule.

Your goal: write a linear rule from a table of values.

1 See it

Three steps to a rule

  1. Find how much y changes each time. That is the multiplier.
  2. Find y when x = 0. That is the constant.
  3. Write: y = multiplier × x + constant.

Example 1: starting at 0

x0123
y7111519

y goes up by 4 each time. When x = 0, y = 7.

y = 4x + 7

Check: 4 × 3 + 7 = 19.

Example 2: not starting at 0

x1234
y9131721

y goes up by 4. Work backwards to x = 0: 9 − 4 = 5.

y = 4x + 5

Lesson 5

Turning words into algebra

Stories often hide a rule. Name the variables, find the starting value and the rate, then write the rule.

Your goal: translate words into expressions and real-life rules.

1 See it

Useful translations

5 more than a number

n + 5

5 less than a number

n − 5

Double a number, then add 3

2n + 3

7 less than 4 times a number

4n − 7

Half a number, then add 9

n/2 + 9

The sum of 3 times a number and 8

3n + 8

Example: taxi fare

A taxi charges a $6 flag fall plus $2 per kilometre.

Let d be the distance and C be the cost.

C = 2d + 6

For 12 km: C = 2 × 12 + 6 = $30.

Look for two numbers: the fixed starting amount (constant) and the amount for each item, hour or kilometre (multiplier).

2 Try it

Build a rule from a story

A hire company charges a $30 booking fee plus $12 per hour.

Let h be the number of hours and C be the cost.

Show the rule

C = 12h + 30

Show the cost for 5 hours

C = 12 × 5 + 30 = 60 + 30 = $90

A plumber charges a $80 call-out fee plus $45 per hour. The bill is $260.

Let h be the number of hours.

Show the equation

45h + 80 = 260

Show the solution

45h = 180, so h = 4 hours.

Your goal: evaluate an expression for a given value of the variable.

1 See it

Replace the letter carefully

Example 1

Evaluate 4x + 7 when x = 3.

4x + 7

= 4 × 3 + 7

= 12 + 7

= 19

Example 2: a negative number

Evaluate 3x + 2 when x = −2.

3x + 2

= 3 × (−2) + 2

= −6 + 2

= −4

Lesson 7

Solving equations

An equation is a balance. To find the value of x, keep both sides equal.

Your goal: solve equations with two operations, such as 3x + 4 = 19.

1 See it

The balance method

Solve 3x + 4 = 19

3x + 4 = 19

Subtract 4 from both sides:

3x = 15

Divide both sides by 3:

x = 5

Check: 3 × 5 + 4 = 15 + 4 = 19.

The backtracking method

x → × 3 → + 4 → 19

Work backwards: 19 − 4 = 15, then 15 ÷ 3 = 5.

Order matters: undo the addition or subtraction first. Then undo the multiplication or division.

Lesson 8

Graphing a linear rule

A linear rule makes a straight line. Build a table, plot the points, then join them with a ruler.

Your goal: graph a linear relationship from a table of values.

1 See it

Graph y = 2x − 1

Table of values
x−2−1012
y−5−3−113

Plot the points: (−2, −5), (−1, −3), (0, −1), (1, 1), (2, 3).

Join them with a straight line and extend it.

Along the corridor, then up the stairs: the first coordinate tells you how far across. The second tells you how far up or down.

Graphing checklist

  • Label the axes.
  • Use an even scale.
  • Plot (x, y) in the right order.
  • Join the points with a ruler.
  • Extend the line.
  • Check one point using the rule.

Lesson 9

Real-life rules

Linear functions are everywhere: taxi fares, savings, phone plans and hire costs.

Your goal: build and use a linear rule for a real-life situation.

1 See it

The modelling routine

  1. Name the variables.
  2. Find the starting value (constant).
  3. Find the rate (multiplier).
  4. Write the rule.
  5. Substitute or solve.
  6. Answer in context, with units.

Taxi

$6 flag fall plus $2 per km.

C = 2d + 6

Savings

$60 saved, then $25 each week.

S = 25w + 60

Phone plan

$30 per month plus $0.10 per MB.

C = 0.10m + 30

2 Try it

Build a cost rule

Choose a fixed cost, a cost per item and a number of items.

Cost builder

Rule: C = 8n + 50

Cost for 5 items = $90

8 × 5 + 50 = 40 + 50 = 90
